# Brand

## Name

Always **Freemy AI**. Never FreeMy, Free My AI, Freem AI or Freemi.

## Tagline

**The AI you own.**

Supporting line: _Your memory. Your models. Your machine. Your rules._

## Voice

Editorial, technical, confident, human. We say what is true today and mark
everything else as planned or in progress. We never say "uncensored",
"no rules", "no restrictions" — freedom at Freemy means _ownership_:
model freedom separated from owner-controlled action authority.

## Color

| Token         | Value                 | Use                                   |
| ------------- | --------------------- | ------------------------------------- |
| Warm Bone     | `#F4F2EC`             | Main background                       |
| Ink           | `#11110F`             | Main text                             |
| Night         | `#0B0C0B`             | Dark sections                         |
| Card          | `#EAE7DF`             | Card surface                          |
| Muted         | `#605D56`             | Secondary text                        |
| Border        | `rgb(17 17 15 / 14%)` | Hairlines                             |
| Signal Green  | `#B7F34A`             | Status, primary CTA, small highlights |
| Signal Bright | `#C7FF61`             | Accent text on dark                   |

Signal Green is an accent — never a full-bleed background.

## Typography

Geist Sans for text, Geist Mono for labels and technical detail. Headlines
use weight 500–600 with `letter-spacing: -0.04em`. Never 900.

## Logo

The mark is an open square frame with an `F` inside — an ownership boundary
that stays open by design. No robots, brains, locks, chains, birds or wings.
Assets live in `public/brand/`.

## Anti-references

Do not imitate generic AI-startup visuals: purple gradients, glowing orbs,
neural-network stock art, random 3D spheres, glassmorphism everywhere,
particle backgrounds.
