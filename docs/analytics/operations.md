# Freemy 作品统计运行说明

作品行为使用 Vercel Web Analytics 的自定义事件，属性只有稳定作品 ID 和语言／页面／入口位置；不发送搜索词。详情浏览和点击是次数，前往原站不代表作品完成体验，访客数是 Vercel 的去重估计。

## 私有报表

生产地址为 `/api/insights`。报表在服务端读取 Vercel 聚合 API；密码或统计令牌缺失时会拒绝提供数据，报表本身和导出结果不允许缓存或索引。用户名为 `freemy`，使用独立生成的长随机密码，不要使用其他账户密码。数据查询失败显示“不可用”，未采集的区间显示“未采集”，部分采集的区间加 `*`。时间筛选按 UTC 解释，选定的结束日期整天包含在内。点击访客估计由平台按作品汇总，不把不同语言或入口的访客数简单相加。

生产环境变量：

- `FREEMY_INSIGHTS_PASSWORD`：至少 43 位的随机 URL 安全字符串，生产环境敏感变量。不要提交到 Git、前端或对话中。
- `FREEMY_VERCEL_TOKEN`：具有读取团队 Web Analytics 权限的 Vercel API 令牌，生产环境敏感变量。优先使用可获得的最小权限，留意有效期及轮换；不要提交到 Git、前端或对话中。
- `FREEMY_EVENTS_STARTED_AT`：普通作品事件实际开始采集的 UTC 时间，当前版本为 `2026-11-12T10:41:00.000Z`。
- `FREEMY_IMPRESSIONS_STARTED_AT`：曝光事件实际开始采集的 UTC 时间，尚未启用时留空。

报表查询超过 100 个不同作品时，若平台返回 `Others`，该项会显示不可用，避免把不完整结果当作零。作品数增长后需要升级分批查询实现。事件匹配曝光的点击率、跨天留存和原站完成体验不在第一版中。

## 采集开关和内部验收

`FREEMY_CUSTOM_EVENTS=1` 且生产构建时，启用预览、原站点击、相关作品、合集和作品详情事件。`FREEMY_IMPRESSIONS=1` 另外控制曝光；只有确认团队用量提醒后才设置，并记录开始时间。两个开关参与构建，修改后需要重新部署。

曝光口径为作品预览区域至少 50% 在视口内连续可见 1 秒，前台页面中每个作品每次打开只记录一次；隐藏搜索结果、被预览弹窗遮挡和后台标签页不计入。

在新标签页访问 `?freemy_analytics=off` 可在该标签页完全排除内部测试的 Web Analytics 和 Speed Insights。访问 `?freemy_analytics=qa` 时，普通页面浏览和性能事件会被排除，作品事件会标记 `qa:`，以便独立验证平台接收；私有报表排除这些事件，但 Vercel 原生事件总数可能仍包含少量 QA 事件。关闭标签页或访问 `?freemy_analytics=normal` 可恢复正常模式。两种模式仅存于当前标签页的会话存储。
